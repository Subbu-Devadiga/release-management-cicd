# Release Management CI/CD Project

This project demonstrates a practical CI/CD pipeline with automated build, testing, deployment, release approvals, and rollback.

## Project Objective

To understand how modern CI/CD practices can be applied to Release Management.

## Planned Pipeline

GitHub → Build → Test → Artifact → DEV → QA → Approval → UAT → Production

## Technologies

- Git
- GitHub
- GitHub Actions
- Docker
- CI/CD
